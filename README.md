# Bug Craft Launcher Updates

Bug Craft Launcher（BCL）的公开更新源与安装包。

## 发布检查

- 每次发布先写清新增、修复、移除内容及兼容限制。GitHub Release 正文和 `latest.json` 的 `notes` 使用同一组变更说明，后者会显示在启动器内。
- 先上传并核对应用包、源码包与 SHA-256，再更新清单。确认旧版可看到新版本、公开下载的哈希一致，且新版本不会提示重复更新。

## 最新正式版：v1.1.5

[下载 Mac 构建、源码和 SHA-256 校验文件，或查看完整更新介绍](https://github.com/baifeng233minecraft/Bug-Craft-Launcher-Updates/releases/tag/v1.1.5)

- 修复 `⌘3` 不响应，数字快捷键按顶部栏顺序排列，自定义键位会检查冲突。
- 新增正版皮肤与披风管理和 Air、Pro、Max、Ultra 启动档位；风扇仍由 macOS 管理。
- 同步系统液态玻璃浓度，调整星光白与深空黑，修复版本及已绑定目录删除。
- 移除房间联机，保留服务器列表、直连和快捷游戏。本版不附第三方中文模组词库，内置中文别名覆盖会减少。

本次仅更新 Apple Silicon Mac，支持 macOS 14 或更高版本，原生液态玻璃需要 macOS 26 或更高版本。应用为 ad-hoc 签名，未经过 Apple 公证；更新非强制，内部更新码 42，构建号 443。启动游戏仍须联网验证 Minecraft Java 版所有权。

仓库已更名为 `Bug-Craft-Launcher-Updates`，历史版本、Issues 和下载资产均保留。更新清单暂时保留历史下载路径，供旧版启动器的下载代理识别；GitHub 会将其重定向到新仓库。请勿重新创建同名的旧仓库，以免破坏重定向。

## v1.1.4 历史更新

[下载 v1.1.4 Mac 构建与源码](https://github.com/baifeng233minecraft/Bug-Craft-Launcher-Updates/releases/tag/v1.1.4)

- 修复浅色模式原生液态玻璃显示，切换深浅外观时即时同步。
- 修复启用玻璃后顶部菜单栏主题色被冲淡的问题。
- 取消原生玻璃卡片的多余外层裁剪，保留系统绘制的边缘折射、光照和阴影。
- 删除登录区长说明文字，正版所有权验证保持生效。
- 移除 Modrinth 启动器实例自动识别、实例列表专用入口，以及后台自动扫描；Modrinth 资源搜索下载与整合包导入保留。
- 移除其他启动器正版账号检测/导入按钮及后台读取代码，正版账号改为通过 BCL 自身的微软浏览器登录。不会删除其他启动器的数据或已保存在 BCL 中的账号。
- Microsoft 登录使用 BCL 自有 AppID 与浏览器 OAuth + PKCE；明确区分应用未获批准和账户/IP 错误。
- 游戏启动和联机房间须通过官方 Java 版所有权与档案验证，离线与第三方身份不能绕过验证；已保存账号也遵守相同要求。

**重要限制：** BCL 的 Minecraft Services AppID 接入申请已于 2026-11-01 提交，目前尚无获批确认，首次正版登录可能返回 `HTTP 403: Invalid app registration`。所有游戏启动均须先联网验证 Java 版所有权；登录或验证失败时无法启动游戏，请了解此限制后更新。本版按维护者要求发布为正式版并推送非强制更新。Windows 版暂停开发，本次不含 Windows 文件。

适用于 Apple Silicon、macOS 14 或更高版本；原生 Liquid Glass 需要 macOS 26 或更高版本。本构建为 ad-hoc 签名，未通过 Apple 公证。发布页附有 SHA-256 校验文件；真正的启动器源码是单独附带的 `BCL-macOS-v1.1.4-source.zip`，不是 GitHub 自动生成的更新仓库源码包。正式版内部更新码为 41，构建号为 442。先前 rc.1 仍为撤回草稿，rc.2 保留为历史预览版。

## v1.1.3 更新介绍

这一版集中改进下载体验、Mod 版本管理、网络测评和界面细节。

### 下载与加载动画

- 下载资源列表不再显示单独的“查看详情”按钮。
- 点击资源卡片任意位置即可直接进入详情页面。
- 下载页面加载时显示真实进度条。
- 加载动画改为猫咪固定在中间，外圈流动线条围绕猫咪旋转。

### Mod 管理

- Mod 管理列表新增“一键切换”。
- 启动器会查找适配当前 Minecraft 版本和加载器的最新模组版本。
- 切换时保持原有启用或停用状态，并自动安装必需前置模组。
- 详情页选择其他版本后立即开始切换，不再需要第二次点击安装。

### 网络测评

- 百宝箱新增完整的网络测评卡片。
- 可检测 Minecraft、Modrinth 和 GitHub 更新服务延迟。
- 下载少量临时数据测量速度，并显示综合评价、平均延迟和 Mbps。
- 测速数据不会保存到本机。

### 界面修复

- 下载资源、原版游戏和 Mod 管理列表统一为更圆润的连续圆角。
- 点击区域、边框和阴影同步适配圆角。
- 修复启动器自定义最小化按钮。
- 改进 macOS 液态玻璃界面，并保留当前主题配色。

### 版本与校验

- 应用版本为 `v1.1.3`，内部更新码为 `38`。
- 更新包继续只使用 SHA-256 校验。
- Apple Silicon 安装包 SHA-256：`6d009a371ee298ecc1fb3b0e83d2b4cf2336396011f70befcfa77e19efd9ddd0`
- 源码包 SHA-256：`42b716cd2bdab1f660e8080e909f49cc2d46b4706fcce0bcb09af18b713722a7`

当前安装包适用于 Apple Silicon 与 macOS 14 或更高版本。
